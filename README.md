\# Smart Greenhouse Mobile Application



\## 📌 Project Overview



A mobile application developed as part of a graduation project

for monitoring and controlling the environment inside a seedling nursery greenhouse.



The application was developed using Flutter (Dart) and integrated

with Firebase Realtime Database for real-time data synchronization

and device control.



\## 🚀 Features



\- Real-time temperature monitoring

\- Real-time soil moisture monitoring

\- Real-time air humidity monitoring

\- Manual and Automatic control modes

\- Watering control

\- Misting control

\- Target humidity setting

\- Scheduled irrigation

\- Support for 3 greenhouse zones



\## 🛠️ Technologies



\- Flutter

\- Dart

\- Firebase Realtime Database

\- ESP32

\- Git / GitHub

\## 👨‍💻 My Responsibilities



\- Developed the mobile application using Flutter (Dart)

\- Designed the application UI for real-time environmental monitoring

\- Integrated Firebase Realtime Database for real-time data synchronization

\- Implemented manual and automatic control modes

\- Developed watering, misting, humidity setting, and scheduled irrigation features

\- Integrated the application with the ESP32-based IoT system



\## 🎓 Project Context



This application was developed as part of a graduation project

titled "Smart Environment Control System for Seedling Nurseries."



The overall system uses ESP32-based hardware to collect environmental

data and control devices inside the greenhouse.
